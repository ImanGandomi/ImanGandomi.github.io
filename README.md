# Iman Gandomi - Personal Website

This is my personal website showcasing my research in computer vision, deep learning, and computer-assisted surgery. Built with Next.js and Tailwind CSS for a modern, professional look suitable for PhD applications.

## Sections

- **About**: Overview of my background and research interests
- **Research**: My focus areas in AI and computer vision
- **Projects**: Key projects in surgical intelligence and AI
- **Publications**: Academic publications and conference papers
- **Experience**: Professional and academic experience
- **Contact**: Ways to get in touch

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- Static export for GitHub Pages

## Deployment

This site is deployed on GitHub Pages. The static files are generated using `npm run build` and served from the root directory.
